# Generation AI Awards — сайт

Откройте `index.html` в браузере — это главная страница. Все кнопки и меню ведут на страницы внутри этой папки.

## Что где лежит

| Файл | Страница |
|---|---|
| index.html | Главная |
| shortlist-2026.html, shortlist-2025.html | Победители и финалисты |
| gallery-2026.html, gallery-2025.html | Галерея |
| jury.html | Жюри |
| ai-navigator.html | AI-Навигатор 2.0 |
| analytical-review.html | Аналитический обзор «От чат-бота к агенту» |
| protocol.html | Положение премии |
| nomination-*.html | 13 страниц номинаций с формой заявки |
| assets/site.css, assets/site.js | Общие стили и скрипты внутренних страниц |
| statuettes-2026.jpg, liga-stavok.webp | Медиа главной страницы (видео загружается с just-ai.com) |

Держите все файлы в одной папке — ссылки между страницами относительные.

## Как менять тексты

Тексты внутренних страниц хранятся в `_source/data/`. Поправьте нужный файл и выполните:

    cd _source
    pip install markdown
    python3 build.py

Все внутренние страницы пересоберутся с одинаковыми шапкой, подвалом и ссылками. Главную страницу (`index.html`) скрипт не трогает — ее редактируют напрямую.

## Что осталось внешним

- Статья «Что думают члены жюри…» живет на generation-ai.ru (кейсориум) — ссылка ведет туда.
- Все картинки (логотипы, фото жюри и галерей) лежат в репозитории: `assets/` и `images/`. С Тильды ничего не загружается.
- Кнопка «Заполнить заявку» на страницах номинаций ведет на рабочую форму на awards.generation-ai.ru. Адрес меняется в одной строке: `APPLY_BASE` в `_source/build.py`.
- Подвал внутренних страниц берется из `index.html` при каждой сборке: поменяли подвал на главной — запустите `build.py`, и он обновится везде.
- Логотипа победителя 2025 года СберЗдоровье пока нет: вместо них показано название. Положите файл в `images/logos/` и укажите путь к нему первым полем в строке `W:` в `_source/data/shortlist_*.txt`.

## Карточки в текстах

В файлах `.md` блок карточек пишется так:

    :::steps
    ### Заголовок первой карточки
    Текст
    +++
    ### Заголовок второй карточки
    Текст
    :::

Виды блоков: intro, qa, callouts, steps, versus, dodont (`+++ dont` — карточка «Не стоит»), experts, icons, template, quote, test, trends, duo.
